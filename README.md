# **Barracuda Ghost Ship**



A RuneLite plugin that allows the user to record and playback Barracuda Trial runs as a ghost racers to be shared or raced against.



**Features**

\- Records exact per-tick position, orientation, sail trims, wind mote

&#x20; releases, and crystal extractor harvests during a trial.

\- Replays a loaded run as a translucent ghost boat alongside you, with

&#x20; colored flashes (and optional text labels, for colorblind accessibility)

&#x20; when it trims sails, uses a mote, or harvests.

\- Follow Mode: the ghost runs a configurable number of ticks ahead of you,

&#x20; with an optional fading path trail showing where it's been.

\- Share runs with friends as a small image, pasted directly via the

&#x20; clipboard - no file uploads needed.

\- Automatic trial-type and rank validation, so a loaded ghost only ever

&#x20; plays back against a matching course.

\- Personal best tracking across every trial and rank combination.
